To convert a pandas DataFrame to a Spark DataFrame, you can use PySpark’s createDataFrame() function from a SparkSession.

✅ Step-by-step Example:
python
Copy
Edit
import pandas as pd
from pyspark.sql import SparkSession

# Step 1: Create pandas DataFrame
pdf = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Charlie'],
    'age': [25, 30, 35]
})

# Step 2: Initialize Spark session
spark = SparkSession.builder.appName("PandasToSpark").getOrCreate()

# Step 3: Convert pandas DataFrame to Spark DataFrame
spark_df = spark.createDataFrame(pdf)

# Show Spark DataFrame
spark_df.show()

🧠 Notes:
PySpark infers schema types from the pandas DataFrame.

If you want to explicitly define the schema, you can pass a schema argument to createDataFrame().


To convert a Spark DataFrame to a pandas DataFrame, use the .toPandas() method:

✅ Example:
python
Copy
Edit
# Assuming you already have a Spark DataFrame called spark_df
pandas_df = spark_df.toPandas()

# Now pandas_df is a regular pandas DataFrame
print(pandas_df.head())
⚠️ Important Notes:
.toPandas() collects all data to the driver, so:

✅ Fine for small to medium datasets

⚠️ Avoid on large datasets — may cause memory overflow

🧠 Tip for Large Data:
If the Spark DataFrame is too big, you can limit rows first:

python
Copy
Edit
